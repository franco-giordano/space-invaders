# Space Invaders

Simple [Space Invaders](https://en.wikipedia.org/wiki/Space_Invaders)-like game in Python. 

![green-background terminal screenshot, showing a player and 6 enemy ships, each represented by a single character](./docs/image.png)

Run with:
```
pip install blessed
python game.py
```

Move with left and right arrows, quit with 'q'.
